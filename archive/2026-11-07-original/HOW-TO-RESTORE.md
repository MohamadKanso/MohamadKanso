# Restoring the original profile README

This folder is an exact copy of the profile README and its galaxy artwork as they were on 7 November 2026, before the KANSO // DEEP FIELD redesign.

To switch back, run this from the repository root, then commit and push:

```bash
cp archive/2026-11-07-original/README.md README.md
```

The original `assets/galaxy.svg` and `assets/orbit.svg` were never modified, so the restored README renders exactly as before. The same version is also tagged `v1-original-readme` in git.
